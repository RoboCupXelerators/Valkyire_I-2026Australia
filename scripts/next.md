### 说明
- 真实采集数据文件：friction_real_sampling_20260519_190045.csv
- 采集内容包括：前后 `x`、左右 `y`、转向 `w` 三个轴的阶跃响应
- 采集结果包含：
  - 指令值：`cmd_vx` / `cmd_vy` / `cmd_wz`

  - 估算速度：`est_vx_cm_s` / `est_vy_cm_s` / `est_wz_deg_s`
  - 开始移动延迟、滑行尾巴等指标

### 目标
1. 分析真机数据，提取模拟器需要调整的参数：
   - deadzone / deadband
   - friction / static friction / dynamic friction
   - damping
   - speed scale / 速度比例
   - yaw 角速度比例
2. 根据不同轴和不同指令幅值，校准模拟器，使其：
   - 起动阈值与真机一致
   - 速度响应曲线近似
   - 滑行尾巴与真机相近
3. 给出可直接用于模拟器的参数配置或设置文件改动建议。

### 任务要求
- 读取并分析 friction_real_sampling_20260519_190045.csv
- 重点给出 `x, y, w` 三轴各自的补偿/缩放参数
- 给出模拟器配置项名称和建议值
- 输出一个可直接应用于模拟器的参数集或改动说明
